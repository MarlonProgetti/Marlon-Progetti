# 👨‍💻 Meu Portfólio

## 📖 Descrição

**Meu Portfólio** é um site pessoal que desenvolvi para apresentar informações sobre mim, como meu nome, idade, curso e formas de contato. O objetivo é tornar essas informações mais acessíveis e visualmente agradáveis, funcionando como uma vitrine digital do meu perfil profissional.
